# Input

A near-square field — `radius-xs`, 1px `ink-muted` border on `canvas`, `inline-label` text in `ink`, uppercase `eyebrow` label above.

Focus turns the border `cerulean` (doubled to 2px with an inset ring). Error turns it `error` (ultraviolet-ink) with a message below in the same colour — this system has no red. The consumer provides the label text and the error message.
