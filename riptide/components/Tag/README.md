# Tag

A one- or two-word section or format label on tiles and in the feed: mono 11/600, 1.8px tracking, UPPERCASE, `radius-tile`, `space-1` × 10px padding.

Tones: `flare` (LIVE and BREAKING only, `on-flare` text), `cerulean` (default, editorial sections), `ultraviolet` (commerce, deals), `spotlight` (`ink` fill, `canvas` text — exclusives, breaking), `quiet` (1px `hairline`, for long tag lists). One saturated tag per tile; never stack two colored tags side by side.
